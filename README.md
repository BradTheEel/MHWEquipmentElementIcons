# Equipment Element Icons 0.2.1

Значок стихии или статуса оружия появляется в левом нижнем углу ячейки. Плагин использует штатные значки Monster Hunter: World.

- **Сменить снаряжение охотника** — оружие в ящике и экипированный слот.
- **Улучшить снаряжение у кузнеца** — список выбора оружия для улучшения.
- **Установить украшения из ящика** — список выбора снаряжения.
- **Сменить снаряжение палико** — оружие в ящике и экипированный слот.

Скрытая стихия показана приглушённо. У парных клинков с двумя эффектами показан основной эффект по данным игры. Оружие без стихии и лукорудия отображаются в обычном виде.

Когда оружие одновременно имеет значок стихии и метку подвески, метка подвески перемещается в свободный правый верхний угол. Если этот угол уже занят, ячейка сохраняет штатное отображение.

В версии 0.2.1 собраны в одном месте правила выбора значка и параметры экипированных слотов. Сценарии автономных тестов запускаются независимо. Сборка и проверка используют общие настройки Zig.

## Установка

[Скачать версию 0.2.1](https://github.com/BradTheEel/MHWEquipmentElementIcons/releases/tag/v0.2.1)

Требуются Monster Hunter: World для Windows x64, Steam build `15539686`, и Stracker’s Loader. Закройте игру и распакуйте `nativePC` из архива в папку с `MonsterHunterWorld.exe`. При обновлении замените прежний `nativePC/plugins/EquipmentElementIcons.dll`.

Чтобы удалить мод, закройте игру и удалите `nativePC/plugins/EquipmentElementIcons.dll`.

## Сборка и проверка

В репозитории находятся исходники, сборочные скрипты, тесты и MinHook с лицензией. В полном архиве релиза эти файлы находятся в `source/`. Запустите `build.ps1 -ZigPath <путь-к-zig.exe>` с Zig `0.13.0`. Скрипт положит DLL в `build/` рядом со сборочными скриптами. Для запуска тестов вызовите `verify.ps1 -ZigPath <путь-к-zig.exe> -LauncherPath <путь-к-launcher.exe>` и укажите лаунчер из `work/owned-test-launcher-v1`.

Автономные проверки покрывают три режима ящика охотника, ящик палико, смену оружия в экипированном слоте, обновление списка, скрытые стихии и восстановление состояния ячеек. Отрисовка в запущенной игре пока не проверена.
